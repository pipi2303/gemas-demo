# PWA Error Fixes - GPIB Bahtera Kasih

## ❌ Error yang Terjadi

```
[PWA] Service Worker registration failed: SecurityError: 
Failed to register a ServiceWorker for scope with script: 
The script has an unsupported MIME type ('text/html').
```

## 🔍 Root Cause

Error terjadi karena:
1. **Konflik antara manual service worker dan Vite PWA plugin**
   - File `/public/service-worker.js` dibuat secara manual
   - Vite PWA plugin juga generate service worker otomatis
   - Browser mencoba load file yang tidak ada, mendapat HTML 404 page

2. **Manual registration di development mode**
   - App mencoba register service worker di Figma iframe
   - Figma iframe environment memiliki security restrictions
   - Service worker tidak bisa berfungsi di iframe environment

## ✅ Fixes Applied

### 1. Deleted Manual Files
```bash
# Removed conflicting manual files
❌ /public/service-worker.js (deleted)
❌ /public/manifest.json (deleted)
```

**Reason**: Vite PWA plugin auto-generates these files. Manual versions cause conflicts.

### 2. Updated PWA Utils
**File**: `/src/app/utils/pwaUtils.ts`

**Before**:
```typescript
export const registerServiceWorker = async () => {
  if ('serviceWorker' in navigator) {
    const registration = await navigator.serviceWorker.register('/service-worker.js');
    // ...manual registration
  }
}
```

**After**:
```typescript
export const registerServiceWorker = async () => {
  // Service Worker is registered automatically by Vite PWA plugin
  // No manual registration needed
  console.log('[PWA] Service Worker will be registered automatically');
  return true;
}
```

**Reason**: Vite PWA plugin handles registration automatically. Manual registration not needed.

### 3. Disabled Dev Mode
**File**: `/vite.config.ts`

**Change**:
```typescript
VitePWA({
  // ... config
  devOptions: {
    enabled: false  // Disable in development to avoid Figma iframe issues
  }
})
```

**Reason**: 
- PWA doesn't work in iframe environments (Figma preview)
- Service Worker requires HTTPS (except localhost)
- Development mode disabled for Figma compatibility
- PWA will work in production build

### 4. Removed Manual Registration Call
**File**: `/src/app/App.tsx`

**Before**:
```typescript
import { registerServiceWorker } from './utils/pwaUtils';

useEffect(() => {
  registerServiceWorker();
}, []);
```

**After**:
```typescript
// Removed - Vite PWA plugin handles registration automatically
```

**Reason**: No manual call needed, plugin handles it automatically.
